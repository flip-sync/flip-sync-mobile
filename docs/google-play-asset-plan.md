# FlipSync Google Play 그래픽 에셋 준비안

Google Play 등록에 필요한 최소 에셋과 추천 캡처 흐름을 정리한 문서입니다.

## 필수 에셋

- 앱 아이콘
  - 형식: PNG
  - 크기: 512 x 512
- 피처 그래픽
  - 형식: PNG 또는 JPG
  - 크기: 1024 x 500
- 휴대폰 스크린샷
  - 최소 2장
  - 권장 6장 이상

## 권장 스크린샷 구성

1. 로그인 / 회원가입 화면
   - 메시지 예시: `이메일로 간편하게 시작`

2. 조직 선택 화면
   - 메시지 예시: `팀별로 작업 공간 분리`

3. 공유방 목록 화면
   - 메시지 예시: `연습방별로 악보 정리`

4. 악보 목록 또는 악보 보기 화면
   - 메시지 예시: `필요한 악보를 빠르게 확인`

5. 악보 업로드 화면
   - 메시지 예시: `이미지로 악보 바로 업로드`

6. 프로필 / 계정 관리 화면
   - 메시지 예시: `프로필과 계정 설정 관리`

## 촬영 가이드

- 실제 기기 또는 에뮬레이터 상태바가 너무 지저분하지 않게 정리합니다.
- 테스트 데이터는 심사자가 앱 성격을 바로 이해할 수 있게 넣습니다.
- 스크린샷 내 문구는 짧고 읽기 쉽게 유지합니다.
- Play 정책상 과장된 순위, 가격, 할인 문구는 넣지 않습니다.

## 피처 그래픽 방향

- 핵심 메시지
  - `합주 팀을 위한 악보 공유와 연습 관리`
- 시각 요소
  - 앱 아이콘 기반 브랜드 컬러
  - 악보/팀/공유를 연상시키는 간결한 비주얼
  - 텍스트는 최소화

## 촬영 전 준비 체크

- 테스트 계정 로그인 가능
- 최소 1개 조직 존재
- 최소 1개 공유방 존재
- 샘플 악보 이미지 업로드 완료
- 프로필 이미지 설정 가능 상태
