# FlipSync 계정삭제 안내 초안

이 문서는 외부 공개 URL에 게시할 계정삭제 안내 초안입니다.

앱의 실제 서버 동작과 운영 절차를 확인한 뒤 게시용 문서로 확정합니다.

- 서비스명: `FlipSync`
- 문의 이메일: `flipsync.score@gmail.com`

## 1. 계정 삭제 방법

FlipSync 사용자는 앱 내 계정삭제 안내 화면에서 계정 삭제를 진행할 수 있습니다.

권장 안내 경로:

- 로그인
- 내 정보 또는 프로필 화면 진입
- `회원탈퇴` 또는 `계정 삭제 안내` 선택
- 현재 비밀번호 입력
- 계정 삭제 확인

외부 공개 페이지에는 실제 앱 경로와 화면 명칭이 최종 확정된 뒤 반영합니다.

## 2. 계정 삭제 시 삭제되는 항목

계정 삭제가 완료되면 다음 정보가 삭제 대상이 됩니다.

- 계정 프로필 정보
- 로그인에 사용되는 계정 정보
- 프로필 이미지
- 사용자가 업로드한 악보 이미지
- 서비스 이용을 위해 생성된 사용자 식별 데이터

정확한 삭제 범위는 실제 백엔드 정책과 일치하도록 최종 검수해야 합니다.

## 3. 삭제 후 예외적으로 보관될 수 있는 정보

다음 정보는 법령 또는 서비스 운영상 필요에 따라 일정 기간 보관될 수 있습니다.

- 보안 및 장애 분석용 로그
- 법령상 보관 의무가 있는 정보

해당 정보는 목적 달성 후 지체 없이 삭제합니다.

## 4. 조직 및 공유방 관련 처리

계정 삭제 시 사용자가 소속 또는 공유방 운영자 역할을 가지고 있는 경우, 다른 구성원이 있는지 여부에 따라 처리 방식이 달라질 수 있습니다.

예시로 아래 항목을 검토해야 합니다.

- 조직장이 탈퇴할 때 소유권 이전이 필요한지
- 공유방 생성자가 탈퇴할 때 방 유지 또는 삭제 기준이 무엇인지
- 마지막 구성원이 탈퇴할 때 조직 또는 공유방을 함께 삭제할지

이 항목은 실제 서버 정책 확인 후 확정 문구로 교체해야 합니다.

## 5. 처리 기간

앱 내 즉시 삭제가 가능한 항목은 계정 삭제 요청 완료와 함께 바로 처리될 수 있습니다.

다만 운영 검토가 필요한 항목이 있다면 아래 기준을 외부 공개 페이지에 함께 기재합니다.

- `[검수 필요]` 즉시 삭제 항목
- `[검수 필요]` 비동기 삭제 항목
- `[검수 필요]` 최대 처리 기간

계정 삭제와 관련한 문의는 아래 이메일로 접수할 수 있습니다.

- 삭제 처리 기간
- 보관 예외 항목
- 조직/공유방 소유권 처리 정책
