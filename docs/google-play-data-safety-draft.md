# FlipSync Google Play Data safety 초안

이 문서는 Google Play `Data safety` 입력용 초안입니다.  
최종 제출 전에는 실제 서버 저장 항목과 운영 정책 기준으로 한 번 더 검수해야 합니다.

## 앱 개요

- 앱 유형: 합주 팀용 악보 공유 및 연습방 관리 앱
- 로그인: 필요
- 사용자 계정 생성: 가능
- 인앱 계정 삭제 경로: 있음

## 수집 가능 데이터 초안

### 1. 개인 정보

- 이메일 주소
  - 수집 목적: 회원가입, 로그인, 계정 식별, 이메일 인증
  - 공유 여부: 현재 기준 외부 광고/마케팅 공유 없음
  - 필수 여부: 예

- 사용자 이름 또는 닉네임
  - 수집 목적: 계정 표시, 팀 내 사용자 식별
  - 공유 여부: 현재 기준 외부 공유 없음
  - 필수 여부: 예

### 2. 사진 및 동영상

- 프로필 이미지
  - 수집 목적: 계정 프로필 표시
  - 공유 여부: 앱 사용자에게 표시될 수 있음
  - 필수 여부: 아니오

- 업로드한 악보 이미지
  - 수집 목적: 공유방 내 악보 저장/공유
  - 공유 여부: 같은 조직/공유방 사용자에게 표시될 수 있음
  - 필수 여부: 기능 사용 시 필요

### 3. 앱 활동 / 사용자 생성 콘텐츠

- 조직 정보
- 공유방 참여 정보
- 악보 업로드 기록

수집 목적:
- 조직 및 공유방 기능 제공
- 업로드 자료 정리
- 사용자 간 공유

### 4. 보안 / 운영 데이터

- 로그인 세션 관련 정보
- 기본 오류 로그 또는 서버 요청 처리 기록

수집 목적:
- 인증 유지
- 장애 대응
- 운영 안정성 확보

## 현재 초안 답변 방향

### 수집 여부

- 사용자 데이터 수집: `예`
- 데이터 공유: `아니오`로 제출하려면 외부 SDK/위탁 전송 범위를 최종 확인해야 함

### 처리 방식

- 전송 중 암호화: `예`로 가는 방향이 적절함
- 계정 삭제 요청 방법 제공: `예`
- 사용자가 삭제 요청 가능: `예`

## 최종 제출 전 확인 필요 항목

- 외부 분석 SDK 사용 여부
- 외부 광고 SDK 사용 여부
- 서버 오류 로그에 개인 식별 정보가 포함되는지 여부
- 이미지 파일 저장 위치와 보관 정책
- 탈퇴 후 즉시 삭제되는 데이터와 법적/운영상 보관되는 데이터 구분

## Play Console 입력 시 메모

- 앱에서 계정을 만들 수 있으므로 `Account deletion` 관련 질문은 반드시 채워야 합니다.
- 개인정보처리방침 URL과 앱 내부 경로가 실제로 열려야 합니다.
- Data safety 답변은 실제 앱 동작과 다르면 심사에서 문제될 수 있으니, 백엔드 저장 구조 기준으로 마지막 검수가 필요합니다.
